# Customer Order Analysis using Python

## Project Overview

* Analyzed e-commerce customer order data using Python.
* Identified customer purchasing behavior and spending patterns.
* Generated business insights using Python data structures.
* Implemented customer classification and category-wise revenue analysis.

## Features Implemented

### Customer Order Processing

* Stored customer records using lists and tuples.
* Organized customer orders using dictionaries.
* Managed structured order information.

### Product Classification

* Categorized products using dictionaries.
* Extracted unique product categories using sets.
* Displayed available product categories.

### Customer Spending Analysis

* Calculated total spending for each customer.
* Classified customers into:

  * High-value buyers
  * Moderate buyers
  * Low-value buyers

### Business Insights Generation

* Calculated category-wise revenue.
* Identified electronics buyers.
* Found top-spending customers.
* Extracted unique products.
* Analyzed multi-category buyers.
